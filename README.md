## 📌 Project Overview

This project is an end-to-end **Insurance Data Engineering Pipeline** developed using Python. It automates the process of ingesting, validating, preprocessing, transforming, and managing insurance datasets while maintaining data quality through logging and retention mechanisms.

The project demonstrates industry-inspired ETL (Extract, Transform, Load) practices and modular software architecture suitable for data engineering workflows.

---

## 🎯 Problem Statement

Insurance companies receive data from multiple sources in different formats. Manual processing is time-consuming and prone to errors.

This project automates the complete workflow by:

- Ingesting raw insurance datasets
- Validating incoming files
- Cleaning and preprocessing data
- Transforming datasets into structured formats
- Generating analytical datasets
- Maintaining logs and retention archives

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/atharvwagh23/Insurance-Data-Engineering-Pipeline.git
```

Move into the project folder

```bash
cd Insurance-Data-Engineering-Pipeline
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the pipeline

```bash
python src/main.py
```
